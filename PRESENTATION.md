### Slide 2: The Core Problem Statement
- **Header:** 01 / The Core Dilemma
- **Title:** Why Traditional Alumni Portals Fail
- **3 Problem Pillars:**
  1. **The Cold-DM Spam Crisis (98% Drop Rate):** Students spam alumni on LinkedIn with generic begging texts (*"Sir please refer me"*). Busy engineers at Google & Swiggy have 0 time to read 5-page resumes, leading them to close their inboxes completely.
  2. **Directory vs. Network (Dead Phonebook Syndrome):** A directory only lists *where* people work. A true network pairs people when their **Intent and Expertise align**. Existing portals have zero reciprocity mechanisms.
  3. **Siloed Campus Ecosystem (Zero Telemetry):** Alumni founders can't find fast campus builders for MVPs; faculty lack industry co-guides for student capstones; and college administrations have zero live data on placement conversions.
- **Speaker Notes (20s):**
  > *"Traditional portals treat alumni like a phonebook. But cold DMs don't work, alumni are overwhelmed with spam, and college administrations have zero visibility into actual hiring conversion. The ecosystem is completely broken."*

---

### Slide 3: The LinkX 6-Role Solution
- **Header:** 02 / The Solution
- **Title:** The LinkX 6-Role Reciprocity Engine
- **6 Stakeholder Cards:**
  - 🎓 **Student:** Proof-of-Work Pitch Lab. No begging DMs. Attaches GitHub repo/PR to generate a 1-minute executive dossier.
  - 💼 **Alumnus:** 1-Minute Decision Radar. Reviews pre-screened AST code metrics and dispatches 1-Click ATS referrals.
  - 🚀 **Founder:** Micro-Bounty Board. Posts ₹5k–₹25k feature tickets with escrow protection; hires verified campus builders in hours.
  - 🏛️ **Faculty:** Industry Capstone Co-Guides. Connects student academic capstones with alumni leads at Google & Swiggy.
  - 🎯 **Recruiter:** Pre-Vetted Talent Radar. Bypasses campus placement lag; filters candidates by AST test coverage and code readiness.
  - 🏫 **Institution:** Accreditation Telemetry. Live analytics on referral conversions, bounty earnings, and alumni density for NIRF/NAAC.
- **Speaker Notes (25s):**
  > *"LinkX replaces one-sided begging with mutual reciprocity across 6 distinct campus stakeholders. Everyone gets a tailored, distraction-free portal with clear incentives."*

### Slide 4: Anti-Cold-DM Pitch Lab & AST Scanner
- **Header:** 03 / Key Innovation
- **Title:** Anti-Cold-DM "Proof-of-Work" Pitch Lab
- **Left Column (The Workflow):**
  1. Zero Raw Text Allowed.
  2. GitHub Repository Staking.
  3. AST Code Analysis (test coverage, complexity, concurrency, P99 latency).
  4. Executive Flash Dossier Packaging.
- **Right Column (The 60-Second Flash Dossier):**
  - **Code Readiness Score:** 94 / 100 (Top 5% Tier)
  - **Primary Stack:** Go / Distributed Consistent Hashing
  - **Test Coverage:** 92.4% Unit & Integration
  - **P99 Benchmark:** 14ms Latency at 10k RPS
  - **Memory:** Zero Goroutine Leaks (pprof verified)
  - **Architectural Highlight:** Robust virtual-node hashing ring distributing keys across cache clusters with zero key drop.
- **Speaker Notes (25s):**
  > *"Here is our core innovation: In LinkX, you cannot send raw text. Students attach a GitHub repo or PR. Our AST engine scans test ratios, cyclomatic complexity, and P99 latency, producing a verified 60-second executive dossier for the alumnus. No begging, pure proof."*

### Slide 5: Alumnus Referral Radar & 1-Click ATS Referrals
- **Header:** 04 / Alumnus Experience
- **Title:** Alumnus Referral Radar: Zero-Lag Decisions
- **4 Key Features:**
  - **1-Click Verified Referral Action:** Dispatches pre-formatted candidate dossiers directly into internal company ATS pipelines (Workday, Greenhouse, Lever).
  - **Constructive Code Feedback Loop:** If not ready, alumnus leaves 2 lines of technical guidance; student refactors and re-applies.
  - **Reputation Staking:** Alumni refer with 100% confidence because code is verified.
  - **Referral Bonus Incentives:** Unlocks up to ₹1.5L in corporate referral bonuses without spending hours screening resumes.
- **Speaker Notes (20s):**
  > *"Alumni can make a referral decision in under 60 seconds. One click pushes the candidate into their corporate ATS, or they give two lines of constructive code feedback so the student can improve and re-apply."*
